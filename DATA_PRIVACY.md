# Data Privacy

## Source data
Sourced directly from **IBM's own GitHub repository** (`github.com/IBM/AML-Data`), titled "IBM Transactions
for Anti-Money Laundering (AML)" -- generated by IBM using a multi-agent virtual-world simulation, per
IBM's own dataset README: "the model and data are NOT based on obfuscating or anonymizing real
individuals. Everything is synthetic." No real account holder, real transaction, or real financial
institution is represented anywhere in this dataset or in this repository's outputs. Also described in
IBM Research's own paper: Altman et al., NeurIPS 2023 / arXiv:2306.16424.

This also means every dollar figure, account identity, and typology pattern this platform scores or
reports on is synthetic -- a finding here is a demonstration of the modeling approach, never a real
compliance finding about a real entity.

## What is excluded from this repository
`data/raw/`, `data/processed/`, and `data/external/` are all excluded via `.gitignore` -- the raw/processed
IBM AML-Data extracts are never committed, regardless of their synthetic nature, to keep the repository small
and to avoid baking a specific dataset release's exact bytes into git history. Trained model artifacts
(`.pkl`/`.joblib`/`.onnx`) and the largest per-row score-baseline JSON files are excluded the same way --
see `MODEL_REGISTRY.md` for what's persisted on disk (but not committed) and how to verify it.

## Real secrets
No API key, token, or credential is ever committed. See `SECRETS_MANAGEMENT.md`.
