# src/aml_riskiq/typology/
AML typology mapping logic - the eight modeled laundering patterns from the source dataset's paper (fan-out,
fan-in, gather-scatter, scatter-gather, cycle, random, bipartite, stack) and any unmapped/other-pattern bucket
(BP1/BP5, Gate 2). Analogous role to a taxonomy module on the prior (complaint-classification) platforms.
