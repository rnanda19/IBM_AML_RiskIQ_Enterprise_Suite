## 2. Dataset size variant - OPEN DECISION, not yet made
The dataset ships six size/ratio variants, each as a paired transaction-log CSV + accompanying
laundering-pattern file: HI-Small, HI-Medium, HI-Large (Higher-Illicit-ratio) and LI-Small, LI-Medium, LI-Large
(Lower-Illicit-ratio, closer to a real-world illicit rate - the paper cites roughly 1-in-1,750 transactions for
LI-Large). Larger variants run into the hundreds of millions of transactions. Which variant(s) to place in
`data/raw/` for this project has not been decided - flagging rather than assuming; a Small variant is the usual
starting point for an 8-core/32GB laptop build given the WARP resource ceilings in `../../configs/resource_limits.yaml`.

## 3. Expected schema (per the dataset's public documentation/paper - UNVERIFIED against a real downloaded file)
[ASSUMPTION - confirm column-by-column once the real file is inspected, per Lessons Learned #1] Publicly
documented transaction-log columns:

```
Timestamp, From Bank, Account, To Bank, Account.1 (counterparty account),
Amount Received, Receiving Currency, Amount Paid, Payment Currency,
Payment Format, Is Laundering
```

`Is Laundering` is the binary ground-truth label (BP1's target). The accompanying pattern file documents which
labeled transactions belong to which of the paper's eight modeled laundering typologies - fan-out, fan-in,
gather-scatter, scatter-gather, cycle, random, bipartite, and stack - which is the natural ground truth for BP5
(Typology & Root-Cause Driver Analytics) and a natural feature/label source for BP4's network analytics. The
exact pattern-file column layout is not yet confirmed and must be read directly off the real file once
downloaded.
